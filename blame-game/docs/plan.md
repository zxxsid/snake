# 甩锅大作战 - 完整项目方案

## 一、游戏概述

**甩锅大作战**是一款实时多人派对小游戏。每位玩家头上顶着一口随时会爆炸的"锅"（倒计时炸弹），必须通过答题把锅甩给其他玩家。锅炸了就淘汰，活到最后的人获胜。

**核心体验**：紧张 + 搞笑 + 社交。答题不是目的，"害别人"才是乐趣。

---

## 二、核心玩法

### 2.1 基本流程

```
创建房间 → 分享给好友 → 3-6人到齐 → 开始游戏
     ↓
每轮：一口锅随机落在某人头上
     ↓
该玩家答题（脑筋急转弯/谐音梗/看图猜词/常识题）
     ↓
答对 → 选一个人甩锅过去 → 对方接锅继续答题
答错 → 锅留在头上，倒计时继续
     ↓
倒计时归零 → 锅爆炸 → 该玩家淘汰
     ↓
剩最后1人 → 获胜
```

### 2.2 锅机制

| 属性 | 说明 |
|------|------|
| 倒计时 | 每口锅初始 15 秒，随局进行逐渐缩短（最短 8 秒） |
| 传递 | 答对题目后，选择一个存活玩家甩锅 |
| 叠加 | 一个玩家可以同时顶多口锅（被多人甩过来） |
| 爆炸 | 任何一口锅倒计时归零即爆炸，该玩家淘汰 |
| 热锅 | 被甩来甩去超过 3 次的锅变成"热锅"，倒计时减半 |

### 2.3 题目类型

| 类型 | 示例 | 难度 |
|------|------|------|
| 脑筋急转弯 | "什么东西越洗越脏？" → 水 | ⭐ |
| 谐音梗 | "猪八戒照镜子" → 里外不是人 | ⭐⭐ |
| 看图猜词 | 显示一张搞笑图片 → 猜成语 | ⭐⭐ |
| 常识判断 | "太阳从西边升起？" → 错 | ⭐ |
| 歇后语 | "姜太公钓鱼 — ?" → 愿者上钩 | ⭐⭐⭐ |

### 2.4 道具系统（可选扩展）

| 道具 | 效果 | 获取方式 |
|------|------|---------|
| 防爆盾 | 抵消一次爆炸 | 连续答对 3 题 |
| 加速器 | 让目标的锅倒计时加速 5 秒 | 随机掉落 |
| 反弹镜 | 下一次被甩锅时自动弹回 | 看广告 |
| 冰冻术 | 冻住自己的锅 3 秒（暂停倒计时） | 连续答对 2 题 |

## 三、页面设计

### 3.1 首页 / 大厅

- 游戏 Logo + 标题"甩锅大作战"
- 玩家头像 + 昵称
- **快速开始** 按钮（创建房间）
- **加入房间** 按钮（输入房间号）
- 排行榜入口（胜场排行）
- 设置入口（音效开关）

### 3.2 房间等待页

- 房间号（大字显示）
- 已加入玩家列表（头像 + 昵称 + 准备状态）
- **分享给好友** 按钮
- **准备 / 取消准备** 按钮
- 房主专属 **开始游戏** 按钮（全员准备后可用）
- 人数要求：最少 3 人，最多 6 人

### 3.3 游戏主界面

```
┌──────────────────────────────────────┐
│  ╭─╮  ╭─╮  ╭─╮  ╭─╮  ╭─╮  ╭─╮    │  ← 玩家头像圈
│  │A│  │B│  │C│  │D│  │E│  │F│    │    淘汰的灰暗显示
│  ╰─╯  ╰─╯  ╰─╯  ╰─╯  ╰─╯  ╰─╯    │    顶锅的头上有锅+倒计时
│                                      │
│          ╭──────────────╮            │
│          │              │            │
│          │   题目区域    │            │  ← 当前题目（文字/图片）
│          │              │            │
│          ╰──────────────╯            │
│                                      │
│     ╭────╮ ╭────╮ ╭────╮ ╭────╮    │
│     │ A  │ │ B  │ │ C  │ │ D  │    │  ← 选项按钮（选择题）
│     ╰────╯ ╰────╯ ╰────╯ ╰────╯    │    或输入框（填空题）
│                                      │
│          ╭──────────────╮            │
│          │   甩给谁？    │            │  ← 答对后选择甩锅目标
│          │  👤 👤 👤    │            │

└──────────────────────────────────────┘
```

**视觉要素**：
- 顶锅玩家头像上方显示"锅"图标 + 红色倒计时
- 锅快炸时（<5秒）抖动 + 变红 + 冒烟
- 爆炸时全屏特效 + 音效 + 被炸玩家表情变 💀
- 甩锅动画：锅从 A 飞向 B 的弧线轨迹
- 弹幕区：实时显示"XXX 把锅甩给了 YYY"

### 3.4 结算页

- 冠军大头像 + 王冠 + 撒花特效
- 排名列表（1-6 名）
- 数据统计：答对数 / 甩锅数 / 存活时长
- **再来一局** 按钮
- **分享战绩** 按钮（生成分享卡片）

### 4.3 通信协议（WebSocket）

**客户端 → 服务端**：

| type | data | 说明 |
|------|------|------|
| `ready` | — | 玩家准备 |
| `answer` | `{ answer: "xxx" }` | 提交答案 |
| `blame` | `{ target: userId }` | 甩锅给目标 |
| `use_item` | `{ item: "shield" }` | 使用道具 |

**服务端 → 客户端**：

| type | data | 说明 |
|------|------|------|
| `room_state` | `{ players, status }` | 房间状态同步 |
| `game_start` | `{ players }` | 游戏开始 |
| `pot_assign` | `{ userId, countdown }` | 锅分配给某人 |
| `question` | `{ id, type, content, options }` | 出题 |
| `answer_result` | `{ correct, answer }` | 答题结果 |
| `blame_anim` | `{ from, to }` | 甩锅动画 |
| `pot_explode` | `{ userId }` | 锅爆炸 |
| `player_out` | `{ userId, rank }` | 玩家淘汰 |
| `game_over` | `{ rankings, stats }` | 游戏结束 |

### 4.4 数据库表

```sql
-- 用户表
users (id, open_id, nickname, avatar_url, wins, games, created_at)

-- 题目表
questions (id, type, content, image, answer, options, difficulty, created_at)

-- 对战记录
matches (id, room_id, player_count, winner_id, status, created_at, finished_at)

-- 对战玩家详情
match_players (id, match_id, user_id, rank, correct_count, blame_count, survive_time)
```

## 五、恶搞元素设计

### 5.1 音效

- 甩锅时："锅是你的了！"（语音）
- 锅快炸时：滋滋滋 + 心跳声
- 爆炸时：BOOM + 惨叫
- 答对时：得意笑声
- 答错时：嘲讽音效

### 5.2 表情弹幕

玩家可以在游戏中发送表情弹幕：
- 😂 哈哈哈
- 🫠 不要给我
- 💀 完蛋了
- 🏃 跑不掉
- 🍳 锅来了
- 👋 再见

### 5.3 恶搞称号

根据表现颁发称号：
- 🏆 **甩锅王** — 甩锅次数最多
- 💣 **炸弹专家** — 第一个被炸
- 🧠 **学霸** — 答对最多
- 🐢 **苟活大师** — 存活最久但没甩过锅
- 🎯 **冤大头** — 被甩锅次数最多

## 七、画面风格

- **整体**：Q 版卡通 + 恶搞涂鸦，类似"整蛊"风格
- **色调**：亮黄 + 橙红为主，热闹喧闹感
- **锅**：黑色大铁锅，顶在头上时歪歪斜斜的
- **爆炸**：不是真实爆炸，而是锅盖飞出 + 烟雾 + 冒出各种食材（鸡腿、辣椒、鱼）
- **人物**：圆脸大头Q版，表情丰富（得意/恐惧/装死）
- **字体**：手写体/漫画字体，加粗有描边
