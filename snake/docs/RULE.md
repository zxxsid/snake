# 贪吃蛇 RPG - 游戏规则

## 基本规则

- 蛇初始长度为 5，初始速度为 5
- 蛇在地图中移动，穿墙不会死亡（从另一侧出现）
- 当蛇的长度小于 2 时游戏结束

## 道具系统

页面中随机散落道具，蛇头碰到道具即可拾取：

| 道具 | 图标 | 效果 |
|------|------|------|
| 心+1 | ♥ | 长度 +1 |
| 心+3 | ♥♥♥ | 长度 +3 |
| 脚+1 | ⚡ | 速度 +1 |
| 剑+1 | ⚔ | 攻击力 +1 |
| 盾+1 | ◆ | 防御力 +1 |

- 道具类型、刷新时间、出现概率、属性值均可通过配置文件修改
- 同时场上最多存在一定数量的道具（可配置）

## 敌人系统

- 每隔一段时间从地图边缘刷新敌人
- 敌人类型包括野猪、野狼等，每种敌人拥有独立的属性：
  - 血量 (HP)
  - 攻击力
  - 移动速度
  - 攻击间隔
- 敌人会朝蛇移动，接近蛇身体后周期性攻击
- 蛇头碰到敌人时，对敌人造成等于蛇攻击力的伤害
- 每次受到攻击，蛇长度减少 = max(1, 敌人攻击力 - 蛇防御力)

## 配置说明

所有游戏参数均在 `src/config.js` 中集中管理，支持热更新：

- 道具类型与属性
- 道具刷新间隔与最大数量
- 敌人类型与属性
- 敌人刷新间隔与最大数量
- 蛇的初始属性
