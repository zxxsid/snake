# 谐音梗大作战 - 游戏规则

## 概述

谐音梗大作战是一款基于微信小游戏平台的猜谜游戏。玩家通过提示图片和谜面图片猜出谐音梗答案，支持单人闯关和双人竞技两种模式。

## 登录

- 使用微信授权登录，获取用户头像和昵称
- 登录后自动同步闯关进度

## 题目结构

每道题包含以下信息：

| 字段 | 说明 |
|------|------|
| 提示图片 | 辅助理解题意的图片 |
| 谜面图片 | 核心谜面图片 |
| 答案 | 谐音梗文字答案 |
| 答案字数 | 答案包含的汉字数量 |
| 分类 | 答案所属类别（动物、人物、歌曲、成语、地名、食物等） |
| 难度 | 关卡难度等级 |

## 闯关模式

### 规则

- 从第 1 关开始，按顺序解锁
- 答对后自动进入下一关
- 答错不扣生命，可反复尝试
- 进度保存在服务端

### 页面元素

- 当前关卡序号
- 提示图片
- 谜面图片
- 答案输入框（按答案字数生成等量方格，一格一字）
- 题目答案分类标签（如"动物"、"歌曲"）
- **确定** 按钮 — 提交答案
- **获取提示** 按钮 — 显示答案的第一个字
- **获取答案** 按钮 — 观看激励广告后显示完整答案

## 竞技模式

### 流程

1. 玩家 A 点击"竞技模式"，自动创建房间
2. 点击"分享"将房间链接发送给微信好友
3. 好友 B 点击链接加入房间
4. 双方就绪后开始对战

### 规则

- 共 **10 道题**，双方题目完全相同
- 每题倒计时 **60 秒**
- 双方起始生命值 **5**
- 扣分规则：
  - 答错 → 生命值 **-1**
  - 倒计时结束未作答 → 生命值 **-1**
  - 主动跳过 → 生命值 **-1**
- 答对不扣生命，进入下一题
- 游戏结束条件：
  - 一方生命值归 0 且对方已答题数超过己方 → 对方获胜
  - 一方已答完全部题目且生命值高于对方 → 该方获胜
  - 双方均答完全部题目 → 生命值高者获胜，相同则平局
  - 一方认输 → 对方获胜

### 页面元素

- 双方玩家信息栏（头像、昵称、生命值）
- 当前题目序号（如 3/10）
- 提示图片
- 谜面图片
- 答案输入框（按答案字数生成等量方格，一格一字）
- 题目答案分类标签
- **确定** 按钮 — 提交答案
- **获取提示** 按钮 — 显示答案的第一个字
- **跳过** 按钮 — 跳过当前题，生命值 -1
- **认输** 按钮 — 直接结束，对方获胜

## 技术架构

- **前端**：微信小游戏（Canvas 2D） + 浏览器开发模式
- **后端**：Go + MySQL
- **实时对战**：WebSocket
- **存储**：题目数据和图片由后端管理
